# Plotweaver

Plotweaver is a platform for creating and managing live action role-playing games (LARPs).

Its purpose is to help organizers design plots, track game content, and coordinate everything needed to run immersive events more smoothly.

## Project Status

This project is currently a work in progress.

## About The Stack

Plotweaver is built on top of the FastAPI full-stack template and customized for the app's domain and product direction.
